#### 2. Тестування функцій за допомогою unittest

Створили функцію `count_symbols()`, яка повертає кількість символів у рядку.

```python
def count_symbols(text: str) -> int:
    return len(text)
```

Для перевірки функції створили тести:

```python
import unittest

class TestSymbols(unittest.TestCase):

    def test_count_symbols(self):
        self.assertEqual(3, count_symbols("abc"))
        self.assertEqual(0, count_symbols(""))
        self.assertEqual(5, count_symbols("Hello"))
```

Перевірили функцію для звичайного та порожнього рядків.

**Результат:** функція правильно визначає кількість символів.

#### 3. Створення функції підрахунку голосних літер

Розробили функцію `count_vowels()`, яка підраховує кількість голосних літер у рядку.

```python
def count_vowels(text):
    vowels = "аеєиіїоуюяaeiouy"
    count = 0

    for letter in text.lower():
        if letter in vowels:
            count += 1

    return count
```

Створили тести:

```python
class TestVowels(unittest.TestCase):

    def test_english(self):
        self.assertEqual(2, count_vowels("hello"))

    def test_empty(self):
        self.assertEqual(0, count_vowels(""))

    def test_numbers(self):
        self.assertEqual(0, count_vowels("12345"))

    def test_ukrainian(self):
        self.assertEqual(3, count_vowels("Україна"))
```

Перевірили функцію для англійських та українських літер, порожнього рядка й цифр.

#### 5. Виявлення та виправлення помилки

Під час перевірки методу `get_figure_length` розглянули ситуацію, коли метод повертає неправильне значення.

Приклад помилкової реалізації:

```python
@property
def get_figure_length(self):
    return 0
```

Після запуску тесту очікуване значення не збігалося з фактичним.

```text
AssertionError: 5 != 0
```

Виправлена реалізація:

```python
@property
def get_figure_length(self):
    return self.length
```

Після виправлення метод повинен повертати правильну довжину фігури.

#### 6. Використання subTest

Створили тест для перевірки кількох значень довжини фігури.

```python
def test_figure_lengths(self):
    for length in [1, 5, 10]:
        with self.subTest(length=length):
            figure = Figure("квадрат", length)
            self.assertEqual(
                length,
                figure.get_figure_length
            )
```

**Призначення `subTest`:** дозволяє перевіряти декілька наборів даних у межах одного тестового методу та визначати, для якого саме набору виникла помилка.

#### 7. Використання unittest.mock

Створили функцію для введення числа користувачем.

```python
def get_number():
    return int(input("Введіть число: "))
```

Для тестування використали `patch`, щоб замінити введення користувача.

```python
from unittest.mock import patch

class TestInput(unittest.TestCase):

    @patch("builtins.input", return_value="5")
    def test_input(self, mock_input):
        self.assertEqual(5, get_number())
        mock_input.assert_called_once()
```

**Призначення `mock`:** дозволяє імітувати введення користувача або роботу зовнішніх залежностей, щоб автоматично перевіряти функції без ручного введення даних.
